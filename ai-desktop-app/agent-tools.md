# LocalMind Agent 2.0

Автономный режим работает по принципу план → исследование → проверка/синтез → сохранение знаний.

Безопасность:
- агент не выполняет произвольные команды ОС;
- веб-данные считаются недоверенными;
- изменения файлов и внешние действия должны проходить через отдельные разрешённые инструменты;
- пользователь может остановить задачу.
